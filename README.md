

\# GraphRAG — AI Knowledge Studio



A document question-answering system built with Generative AI, Retrieval-Augmented Generation (RAG), and Neo4j vector search.



\## Features



\- PDF text extraction and chunking with Docling

\- 3072-dimensional embeddings using Gemini

\- Semantic vector search using Neo4j

\- Context-grounded answers generated by Gemini

\- Source chunk retrieval and similarity scores

\- RAGAS-based answer evaluation

\- Gradio web interface for uploading and querying documents



\## Architecture



PDF → Docling → Text Chunks → Gemini Embeddings → Neo4j Vector Index



User Question → Query Embedding → Vector Retrieval → Relevant Context → Gemini Answer



\## Technology Stack



Python, Gradio, Google Gemini API, Neo4j, Docling, RAGAS, LangChain.



\## Local Setup



1\. Create and activate a Python virtual environment.

2\. Install the packages using `pip install -r requirements.txt`.

3\. Configure the environment variables in `.env`.

4\. Start the application using `python app.py`.



\## Environment Variables



Configure `GEMINI\_API\_KEY`, `NEO4J\_URI`, `NEO4J\_USER`, `NEO4J\_PASSWORD`, and `NEO4J\_DATABASE`.



Never commit your `.env` file or API keys.



\## Deployment



A cloud deployment requires a reachable Neo4j database and securely configured environment variables.
